# Homebrew Tap for asiai

Multi-engine LLM benchmark & monitoring CLI for Apple Silicon.

## Installation

```bash
brew tap druide67/tap
brew install asiai
```

## Usage

```bash
asiai detect          # Detect Ollama / LM Studio
asiai models          # List loaded models
asiai bench           # Cross-engine benchmark
asiai monitor         # System metrics snapshot
```
